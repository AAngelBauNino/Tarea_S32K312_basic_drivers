# Tarea S32K312 - Basic Drivers

Proyecto desarrollado para la materia de **Sistemas Embebidos**.

El objetivo de este proyecto es desarrollar e implementar drivers básicos para el microcontrolador **NXP S32K312**.

## Hardware
- MCU: NXP S32K312
- Plataforma: S32K3
- IDE: S32 Design Studio

## Contenido
El proyecto incluirá progresivamente drivers y ejemplos para diferentes periféricos del microcontrolador.
